## ⚠️ 教训（重要）
- **切勿用 `git rm`/`git mv` 直接处理中文路径文件**！Git Bash 下中文路径会被错误处理，曾误删整个 `assets/` 目录（30文件全没了，靠 `git checkout HEAD -- assets/` 恢复）。
- 正确做法：用 **Python `os.remove` / `os.rename`** 做中文路径的删除与重命名，再 `git add -A` 更新索引（git 自动检测重命名）。
