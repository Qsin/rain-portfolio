HOW I WORK · CREATIVE FLOW

一条内容的诞生 Creative Process

从选题脚本到上线复盘，兼顾内容与实际传播效果。

01📋

策划 · 脚本

结合热点与用户画像确定方向，撰写脚本，设计开篇钩子。

  • 竞品分析 + 选题筛选
  • 脚本分镜 / 文案配文
  • 钩子设计 · 前3秒策略
02🎥

素材 · 生成 / 拍摄

素材·生成：AIGC生成素材，做提示词调优、素材筛选；具备基础实拍实践。

  • 即梦 / tapnow / libv 生成
  • 提示词优化 + 素材抽卡
  • 选图/选片段 · 风格统一
03✂️

剪辑 · 包装

剪辑·包装：剪映/PR剪辑合成，PS调色，制作字幕配乐卡点，处理画面穿帮变形问题。

  • 剪映 / PR / AE 合成
  • PS 修图 · 画面调色
  • 字幕 · 配乐 · 节奏卡点
04📈

发布 · 复盘

发布·复盘：内容分发上线，关注点击率/完播率/互动数据，迭代优化后续内容。

  • 标题 / 封面 / 发布时间策略
  • 达人对接 · 社群分发
  • 播放 / 转化数据复盘迭代
